# Fitness Assist - Фитнес-приложение

## Описание
Полноценное фитнес-приложение для отслеживания тренировок, водного баланса, питания и прогресса. Поддерживает несколько пользователей с разделением данных.
 
## Основной функционал
Аккаунт и профиль:
- Регистрация и вход по email
- Гостевой режим без регистрации
- Персональный профиль с фото
- Расчет ИМТ, BMR и нормы калорий
- Статистика тренировок

Тренировки:
- Создание собственных тренировок - название, описание, набор упражнений
- Библиотека упражнений - 10+ базовых упражнений с описанием техники
- Выполнение тренировок - таймер, подходы, повторения, вес, отдых
- История тренировок - дата, длительность, выполненные упражнения
- Статистика - общее время, количество тренировок, сожженные калории

Водный баланс:
- Отслеживание выпитой воды
- Настраиваемая дневная цель
- Прогресс-бар с цветовой индикацией
- Автосохранение прогресса

Питание:
- Подсчет калорий с прогресс-баром
- Быстрое добавление готовых продуктов
- Добавление собственных продуктов - название, калории, категория
- Избранное и поиск по продуктам
- Настраиваемая дневная цель калорий

Настройки:
- Управление целями водного баланса
- Сброс данных текущего пользователя
- Выход из аккаунта

## Технологии
- Язык: Kotlin
- Минимальная SDK: 21
- Архитектура: Single Activity с Fragment
- Хранение данных: SharedPreferences
- Навигация: Navigation Component

## Фрагменты:
- LoginFragment - экран входа/регистрации
- HomeFragment - главное меню
- WorkoutFragment - таймер тренировки
- CustomWorkoutFragment - создание своих тренировок
- ExerciseLibraryFragment - библиотека упражнений
- WorkoutExecutionFragment - выполнение тренировки
- SimpleWorkoutHistoryFragment - история тренировок
- WaterFragment - водный баланс
- NutritionFragment - питание и калории
- CustomFoodsFragment - свои продукты
- SettingsFragment - настройки
- UserProfileFragment - профиль пользователя

## Классы данных:
- UserProfile - профиль пользователя
- CustomWorkout / Exercise - тренировки и упражнения
- WorkoutHistory / ExerciseHistory / SetHistory - история тренировок
- CustomFood - пользовательские продукты
- UserPrefsUtils - утилита для работы с SharedPreferences (с привязкой к пользователю)

## Установка
1. Распакуйте ZIP-архив и положите папку приложения в папку с проектами Android Studio
2. Откройте проект в Android Studio
3. Запустите на эмуляторе или реальном устройстве
